# PolarAgent UI 设计稿 v2（ASCII 线框 · 待拍板）

- 版本：v2 · 2026-09-10
- 状态：待拍板（F 节列出需确认取舍）
- 技术栈：Electron 44 + React 19 + Tailwind CSS v4 + shadcn/ui + @assistant-ui/react 0.15 + motion 13（animate-ui 同源动画）+ lucide-react
- 规范来源：assistant-ui `design.md`（印刷文档隐喻）+ 本次重构约束
- 窗口基准：1280×800；最小 960×600；Windows 优先
- 读图说明：线框以等宽字符绘制，单行 ≤ 110 字符；中文按双宽渲染时边框可能差 ±1 列，不影响阅读。

## 0. 设计基调（总约束）

| 维度 | 决策 |
| --- | --- |
| 隐喻 | 印刷文档。界面是纸与栏，不是卡片堆叠；靠字重、留白、明度分层撑起层级。 |
| 圆角 | page 0 / document 6 / control 8 / surface（菜单、popover）10 / xl（dialog、toast）12 / thread 16（仅聊天表面）。禁止装饰性大圆角。 |
| 线条 | 仅 section 之间 border-t；优先 hover 背景、密度、mono 眉题。禁止描边卡片墙、装饰分割线。 |
| 颜色 | Chrome 单色：单一 `--tint` 控制全部中性色，只用明度分层。唯一强调色 #b99af1，落点见 E2。 |
| 排版 | display（衬线，欢迎语/设置标题/审批结论）、sans（界面与正文）、mono（代码、路径、命令、眉题、数字）。标题须是完整句子。 |
| 动效 | 只解释状态变化、保持连续性、确认操作；120–200ms。全部尊重 `prefers-reduced-motion`。禁止装饰性动效。 |
| 深度 | 平面 + 1px 边框 + 明度台阶；仅浮层（菜单/popover/dialog/toast）允许轻微 lift。禁止渐变、glow、玻璃态、纹理、彩虹徽章、装饰图标。 |

## A. 变更总览（与现有界面相比的结构性变化）

1. **顶栏统一为 44px 带**：左侧品牌 + 折叠按钮 + 搜索，右侧标题 + 运行状态点 + 统计 + 窗口控制；整条拖拽。去掉 `border-b/40`、`bg-white` 等硬编码，统一到 `--border` / `--background`。
2. **侧边栏重构**：日期分组（今天/昨天/更早）、fork 父子缩进、底部用量汇总浮层、48px 图标轨道折叠态；**搜索入口统一到「展开/收起」按钮右侧**，不再在侧栏内做标题筛选。
3. **Composer 升级为控制台**：附件（拖拽/粘贴）、权限模式 chip、模型选择、思考等级、工作目录、发送/停止/排队/插话；斜杠菜单用 Command 实现；拖拽态、运行态、队列态各有面貌。
4. **消息层新增**：底部操作栏含「分支」（GitBranch）；消息级用量（克制 mono）；日期分隔；压缩摘要标记；向上加载；长会话虚拟化。
5. **新增审批体系**：三模式切换（默认权限 / 帮我审批 / 完全访问）+ 审批卡五态（默认、二次确认、AI 审批中、AI 结论、已拒绝）。
6. **一个搜索**：侧栏搜索按钮与 Ctrl+K 打开同一个搜索模态窗（会话 / 消息 / 设置 / 命令 四组，输入即搜，点会话跳转会话、点消息定位到那条消息）。
7. **设置模态扩为六分类**：通用 / 模型服务 / 权限 / 技能 / 个性化 / 关于；模型服务表单含拉取模型与连接测试；权限面板含三模式与规则表。
8. **令牌调整**：`--accent` 回归中性 hover 色；品牌独立为 `--brand*` 家族；新增 `--tint` / `--font-display` / `--font-mono` / `--sidebar-accent` / `--destructive-foreground`。
9. **圆角收敛**：Composer 24px→16px；用户消息 12px→6px；发送/附加按钮 rounded-full→8px；建议卡 rounded-full→6px；菜单 12px→10px；滚动到底按钮 rounded-full→8px。
10. **不变**：左右两栏骨架、assistant-ui 作为消息渲染核心、`.dark` 切换、`--chat-font` / `--chat-font-size` 机制。

- ① 用户消息底部操作栏（hover 或键盘聚焦时出现）：复制 / 编辑。编辑**不在气泡里就地展开**，而是开模态（见 B8）。
- ② 推理折叠：默认折叠为一行 mono 眉题「思维链 · 已用 Ns」；运行中标签走 shimmer + 品牌脉冲点；展开后为小字、低对比正文。
- ③ 工具分组折叠：默认折叠为一行眉题；运行中显「已运行 N 个工具 · 正在运行 <名称>」；展开后逐条列出（✓ 完成中性 / ◐ 运行中品牌点 / ✕ 失败并加重 destructive）。
- ④ Markdown 正文：sans、行高 1.7；代码块 document 圆角 + `--secondary` 底 + mono，右上角复制按钮 hover 出现。
- ⑤ 助手消息底部操作栏：复制 / 重试 / 分支 / 更多；右侧为用量（mono 11px、低对比，流结束后才出现）。
- ⑥ 停止生成态：停止键为品牌实底方块；左侧一行说明「停止将在当前步骤结束后生效」——工具执行中不可中断，避免留下半写文件。

- ① 向上加载：viewport 顶部哨兵，距顶 400px 触发；加载中显示 3 行骨架；完成后保持当前锚点（scroll anchoring）不跳动。
- ② 压缩摘要标记：折叠为一行 mono 眉题，标注覆盖范围与 token；展开为摘要正文（左侧 2px 中性竖线引用样式）；「查看原文」跳到被压缩的第一条消息。
- ③ 虚拟化：窗口化渲染 + 1 屏 overscan；视口外消息保留等高占位，滚动条长度稳定；进出视口 150ms 淡入（reduced-motion → 无）。
- ④ 消息级用量：默认常显（mono 11px、低对比）；hover 出明细 popover（输入/输出/缓存）。未结束时显示实时耗时。
- ⑤ 操作栏在消息 hover 或聚焦时出现，常态保持低存在感。
- 日期分隔：仅跨天插入，mono 眉题；同一天首条不显示；这是全界面少数允许的横线之一。

### D1 状态与指针规则

| 状态 | 规则 |
| --- | --- |
| hover | 仅背景明度变化（约 ±4%），120ms；不位移、不改布局、不加阴影。 |
| focus-visible | 2px `--ring` + 1px 偏移；仅键盘触发；鼠标点击不显示环。 |
| active | 底色再降一档；按钮可 0.98 缩放（120ms），其余不缩放。 |
| selected | 侧栏当前会话：`--brand-muted` 底 + 左侧 2px 品牌条；菜单选中：中性 `--accent` 底。 |
| disabled | 文字 `--muted-foreground`，无 hover；发送键在空输入时禁用但保留占位。 |
| loading | 骨架或 shimmer，不阻塞滚动；提交类按钮禁用并改文案（如「保存中…」）。 |
| 危险 | destructive 只用于文字与边框；删除类操作一律走 ConfirmDialog。 |

### D3 审批流状态机

```
低风险自动放行 ──► allowed（不经过 UI）
                                    ┌─ 允许一次 ─────────► allowed(once)
                                    │
 工具调用 ─► pending ────────────────┼─ 始终允许 ─┬ 本会话 ─► allowed(session)
 （命中询问规则）                    │            └ 永久 ───► allowed(always)
                                    └─ 拒绝并说明理由 ─────► denied(reason)

 高危操作（删除/覆盖/危险命令）：
 pending ─► confirm2（二次确认 Dialog）── 确认 ──► allowed
                                 └─ 取消 ──► pending

 帮我审批模式：
 工具调用 ─► pending ─► ai_reviewing（「AI 审批中…」）─┬─ allow ─► allowed（附理由）
                                                     └─ deny ──► denied（附理由）
                              ▲                              
                              └── 用户「改为由我确认」随时接管 ──► pending
```

- 每条 pending 都会在 Composer 上方吸顶显示计数，离开当前会话也可见（侧栏会话项加一个中性「待确认」点）。
- 拒绝理由写入会话记录；AI 审批的「永久允许」仍需遵守规则表白名单，不可绕过硬拒绝规则。

### D4 分支跳转流

```
[消息底部 ⑂ 分支]
   └─► 取「这条消息及其之前的所有消息」
        └─► 创建新会话（标题：原名 · 分支；parentId=原会话）
             └─► 立即切换到新会话（不弹确认）
                  └─► 滚动到底部，Composer 自动聚焦
                       └─► Toast「已从这条消息创建分支」[撤销]
撤销窗口 8s：仅当新会话无新消息时可撤销 → 回到原会话并删除该分支。
```

- 侧栏中父会话展开即见子项；子项标题默认继承「原名 · 分支」并可重命名。
- 原消息上保留一个轻量「已在此处分支」标记（mono 眉题，可点击跳到该分支）。

### D5 排队消息生命周期

```
空闲 ──输入 + Enter──► 发送中 ──► 流式运行中
                                      │
                     运行中再输入 + Enter ──► queued（Composer 上方列表，可撤销）
                                      │
                     当前轮次结束（工具/回答收尾）──► 自动出队 ──► 发送中 ──► …
                                      │
                     运行中 + Ctrl+Enter ──► 插话：打断当前流 ──► 立即发送（标记「已插话」）
```

- queued 项支持：撤销（移出队列）、插话（提前为下一条立即执行）、编辑（点文字回到输入框）。
- 队列上限 5 条，超出时禁用发送并提示「队列已满，先等一轮或插话」。
- 会话被删除/停止时，队列清空并给出一次 Toast 说明。

### D6 浮层层级与 Esc 关闭链

```
Esc 从上到下逐层关闭：
  1. 斜杠菜单 / 下拉菜单 / popover
  2. 队列项编辑态 / 附件预览
  3. 搜索模态窗
  4. 设置模态 / 编辑消息模态（有未保存修改时先弹确认）
  5. 审批卡：不关闭、不拒绝；Esc 只把焦点移回 Composer（防误触）
```

- 同一时刻只允许存在一个非模态浮层；打开新浮层自动收起上一个。
- Dialog 打开时焦点锁在内部，Tab 循环；关闭后焦点回到触发元素。
- toast 不参与 Esc 关闭链，超时自动消失，可手动 ×。

## F. 设计待确认点清单（需拍板，按优先级）

**P0-1 主按钮用品牌紫还是墨色**
建议：发送键与「允许一次」用品牌紫实底；其余确认类（保存、重命名）用墨色。若希望更冷、更克制，可整体改墨色，品牌只留在第 3/4/5 类落点。

**P0-2 display 字体是否打包**
建议：打包 Source Serif 4 + Noto Serif SC 子集（约 +1–2MB）。不打包则 Windows 回退到宋体，印刷感打折。

**P0-3 权限模式 chip 是否常驻 Composer**
建议：常驻。权限是安全关键信息，应始终可见；仅在「完全访问」时把 chip 文字改为偏高警示（用中性色 + mono 标注，不用红）。

**P1-4 长会话虚拟化实现**
建议：窗口化渲染 + 等高占位（而非仅 content-visibility）。后者实现便宜，但滚动条长度不反映真实内容，长会话体验差。

**P1-6 运行中 Enter 的语义**
建议：Enter = 排队（保守，不打断）；Ctrl+Enter = 插话。反向（Enter 插话）更快但容易误打断工具执行。

**P1-7 停止键的行为边界**
建议：工具执行中不硬中断，本轮结束后生效（如 B2 ⑥）；若产品希望「立即停止」，需接受可能留下半写文件。

**P2-8 fork 子项在侧栏的默认可见性**
建议：父项默认展开（含活跃子项时）；子项折叠记忆到本地。

**P2-9 消息级用量是否常显**
建议：常显但 mono 11px、低对比；若嫌吵改为 hover 才显示，默认隐藏。

**P2-10 顶栏是否保留「会话统计」按钮**
建议：移除，统一到侧栏底部用量 popover，避免同一信息两处入口。

**P3-11 AI 审批会话的查看入口**
建议：审批卡内「查看审批过程」直达；设置 → 权限 里可查历史审批记录。不新增侧栏常驻入口。

**P3-12 队列项能力范围**
建议：撤销 + 插话 + 编辑三件套；若想更简，砍掉编辑（点队列项仅定位到输入框）。

**P3-13 是否允许 Esc 关闭审批卡**
建议：不允许。Esc 只把焦点移回 Composer，防止误触放行或误拒。

**P3-14 附加快捷键**
建议采纳：Ctrl+N 新对话、Ctrl+B 折叠侧栏、Ctrl+, 设置、Ctrl+/ 斜杠菜单、F2 重命名。
可选（需确认）：Alt+↑/↓ 切换模型、Ctrl+Shift+H 折叠全部推理块。

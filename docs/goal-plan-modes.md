# Oint 的目标与计划能力

Oint 只有两种工作方式：智能体默认直接完成工作；编排在有收益时委派独立任务，负责整合和验证。两者都可使用 Goal、Plan、Todo 和 Task，没有独立计划模式。

| 能力 | 内容 |
| --- | --- |
| Goal | 结果、验收标准、证据与持续推进状态 |
| Plan | 完整 Markdown 方案、取舍与不可变内容版本 |
| Todo | 执行步骤的实时进度 |
| Task | 有明确边界的子任务及其交付结果 |

简单请求无需创建卡片。保存或展示方案不会自动创建目标、授权执行或改变工作方式。默认与编排共用相同的授权与验证规则。

## 工作约束

输入框的“新工作”菜单可以提交仅规划、只读调研或直接执行的一次性请求。选择随这一条消息提交，不改变会话模式。后续消息属于当前工作，限制一直保持；开始另一项工作会使用新作用域，归档此前方案、暂停此前目标，并取消旧子任务。

每条普通用户输入先登记为待处理。模型理解需求后，通过 `set_work_contract` 处理输入：仅规划请求设 `effects: read-only`，先评审请求设 `requiresReview: true`。在这之前只开放读取、提问及应用内元数据工具。自然语言由模型解释，宿主强制执行已登记的约束；模型不能自行放宽用户限制。明确的“新工作”菜单和“开始计划”按钮提供结构化控制。

解释步骤或询问进度不改变方案版本。改变需求时提高独立的需求版本，旧方案不能直接执行；待处理或尚未进入对话的排队消息不能被提前确认。

受限工作禁止文件修改、任意 shell、未知 MCP、浏览器操作及后台启动。读取、检索、方案保存与受相同限制的委派仍可用。插件钩子在受限运行中不加载；已捕获的钩子在调用前再次检查当前约束。子任务在创建事务中持久化父工作权限上限，恢复后也不能借用另一项工作的权限。收紧限制或停止运行会取消可取消的子任务和后台作业。

## 计划查看、修订与执行

主 AI 使用 `read_plan`、`save_plan`、`present_plan` 管理正式方案。更新需提供准确的工作与计划版本。正文保存于原生 `PlanDoc`；历史版本可直接查看，不依赖外部文件、路径或哈希。方案有草稿、就绪和归档三种状态；就绪表示内容已形成，不代表获准实施。

计划卡提供查看、历史、修改、开始与归档。修改意见通过当前工作发送，不消耗输入框里尚未发送的草稿。要求重新评审时，修改正文会撤销旧批准；普通已授权工作可按范围调整方案并继续，不重复要求批准。

“开始计划”绑定计划 ID、内容版本、工作版本和唯一请求 ID。宿主核验当前内容、需求版本与待处理输入后预留执行。授权、冻结的正文、原生输入和运行任务在同一事务中受理；取消或失败不会遗留预授权。相同请求可重放，已开始的版本不能再次提交。工作方式沿用用户当前选择。

归档撤销该方案的执行授权，但不会授予更大权限。历史内容可保留查看；不同工作间不共用执行许可。

## 持久化、分支与目标续行

Goal、Plan、工作约束和执行凭据分别存储，界面从同一持久状态投影。完整正文按需读取，系统提示只注入摘要和版本。上下文压缩不会丢失这些文档。

重开会话恢复内容和约束，不自动继续目标或已开始的计划运行。没有被受理的计划预留会释放。历史分支继承方案和限制，不继承执行凭据；原对话的收件箱标记不会作为新分支的待处理输入。

目标只在当前工作、无优先输入且空闲时自动续行。scope 为 research 的研究目标可在只读约束内继续；scope 为 implementation 的实施目标只有在实施权限和评审都满足后才续行。目标 active 不会增加权限。只有实际受理的自动轮次消耗额度。默认上限 10，可设置 1–100；继续目标重新给予所配置的额度。

人工暂停只能由“继续目标”恢复；普通消息、计划执行、切换工作方式都不会恢复暂停目标。完成必须由模型根据实际证据确认全部验收标准；勾完 Todo 不自动完成 Goal。

## 实现与验证

核心文件：`workflow.ts`、`tools/workflow.ts`、`execution-policy.ts`、`runtime.ts`、`subagent-runner.ts`、`native-view.ts`；界面位于 `Composer.tsx` 与 `ComposerDock.tsx`。

不保留旧计划模式、返回模式、工作流文档读写器或计划文件读取特例，不迁移旧数据。

验证命令：`npm test`、`npm run build`、`npm run check:i18n`、`npm run check:unwired`。实现证据与剩余检查记录在开发进度文件中；调研依据见 [重构报告](./planning-capability-report.md)。

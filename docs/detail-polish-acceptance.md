# 会话与交互细节优化验收

本轮按已确认的 20 项清单推进。保留工作区原有改动；本文件仅记录本轮行为和验证，不将原有功能重复算作新增。

## 三种模式

- 默认：直接处理任务。
- 编排：以委派、综合与验收为主。
- 计划：允许内置阅读、检索、网页调研和提问；禁止写文件、执行命令、后台作业、浏览器操作、子智能体委派和未验证的第三方工具。插件扩展在计划运行中不装载。
- “开始执行”先保存默认模式，再发送执行消息；保存失败不发送。仅选择模式不会自动执行。
- 模式以一次运行为边界。运行中修改的是下次发送的模式，当前运行及恢复后的未完成任务仍遵守原有模式。

## 验证

- 全量回归：193 个测试文件通过，2475 项测试通过，18 项跳过；后续细节修正另做定向回归。
- 后续修正：文件保存与列表恢复相关 35 项、欢迎页相关 13 项定向测试通过。
- 完整 TypeScript 检查、国际化词条检查、正式构建通过。
- 真实 Electron 冒烟检查：三模式入口、960 像素布局、关闭最后标签后的侧栏宽度归零通过。
- 定向测试涵盖实际原生运行时只读门禁、恢复后的权限保持、恢复执行、草稿保存竞争、失败恢复、搜索定位与快捷键。

## 行为边界

- 计划模式目前禁用全部第三方 MCP / 插件工具及委派，即使工具自称只读。它不会停止此前执行模式已经启动的独立后台工作。
- 文件编辑草稿支持本机重启恢复；会话输入草稿目前在本次应用运行期间按会话保留。
- 文件保存先检查磁盘变化，但检查和写入不是文件系统级原子操作，极短的外部并发写入窗口仍存在。
- 搜索仍覆盖已加载的消息，未引入全库全文索引；标签页保持原有运行期状态，不新增跨重启浏览器会话恢复。

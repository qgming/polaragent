# 请求错误与自动重试

网络断开、请求超时、临时限流和服务端故障由原生模型请求重试机制处理，最多重试 5 次（首次请求加 5 次重试，最多 6 次请求）。密钥无效、额度耗尽等配置类错误直接显示详情。

重试期间，消息尾部显示灰色 Wi-Fi 图标和“正在重新连接 2/5”一类状态。点击可展开完整错误详情；同一请求的连续失败不重复显示红色消息卡片。重试耗尽后，输入框上方显示一张明显的红色错误详情卡片，内容可滚动查看。

重试只重新请求失败的模型步骤，保留已经执行的工具、已发送的用户输入和部分回复。成功、停止或开始新的请求后，当前重连状态会清除；切换会话后通过原生快照恢复对应会话的状态。历史失败仍可通过折叠行查看。

## 实现

- `src/main/pisdk/model-retry.ts`：重试上限与原生状态投影；按 generation 统计实际重试次数。
- `src/main/pisdk/runtime.ts`：开启原生重试，关闭供应商层的额外重试，避免两层次数叠加。
- `src/main/pisdk/native-view.ts`、`message-mapper.ts`：实时、历史和重开会话使用同一代请求标识。
- `src/renderer/features/chat/RequestRetry.tsx`：可展开的重连状态与最终错误卡片。
- `Thread.tsx`、`message-parts.tsx`：错误展示去重，保留部分输出。

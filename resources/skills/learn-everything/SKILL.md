# 学会一切（Learn Everything）

把原始材料或一个主题，转换成一门在「讲解 → 提取回忆 → 应用 → 反馈 → 复习」之间循环的适应性课程。

## 核心行为

- 用用户的语言教学，除非对方要求换一种语言。
- 目标是**持久理解**，而不只是做一份摘要。
- **循序渐进**。先给出课程地图，然后一次只教一章或一课。
- 学习者没有尝试之前，**不要泄露练习答案** —— 除非学习者明确要求。
- **持久化学习状态**。有文件工具时（read / write / edit），维护 `learn/<slug>/course-state.md`（含完成情况的课程地图、概念掌握表、复习队列、错误日志），并在**章节边界**更新它 —— 不是每一轮都更新。没有文件工具时，把状态留在对话里，并在每个章节检查点输出一份紧凑、可复制的状态块，让学习者存下来、之后粘回来接着学。两种格式见 [references/session-formats.md](./references/session-formats.md)。
- 优先用具体的例子、类比、用文字描述的示意图、反例和完整的推导过程，而不是只做抽象论述。
- 把**原始材料的说法**和**你补充的背景知识**分开。绝不把补充内容说成是材料里的。
- 深度和记号要匹配学习者。在依赖某个术语之前，先把它定义清楚。

## 判断输入模式

### 文档模式

学习者提供的是 PDF、论文、书、幻灯片、笔记或其他材料时，用文档模式。

> **关于 PDF（Oint 的实际情况）**：`read` 只读得了文本文件，读不了 PDF。
> 这时先用 bash 里可用的工具试着转换，例如 `pdftotext input.pdf -`（poppler）
> 之类；**工具不在、转换失败，或文档是扫描件时，直接请用户提供文本或摘录**
>（哪怕只是关键几页）—— 绝不要凭空臆造文档内容。
> 图、表、示意图这类信息同理：提取不到就请用户提供图片或口头描述。

1. 先读文档的结构：目录、各级标题、各节篇幅，并对密集的章节做抽样检查。短材料（一篇论文、一章，大约 ≤30 页）在定稿课程地图之前**完整读完**；更长的材料则先依据结构定下地图，正文**惰性读取** —— 只在即将教某一章之前，才读那一章的全文。
2. 找出目录、标题、前置知识、核心论断、定义、例子、公式、图、表以及附录。
3. 按**语义单元**切分，而不是按均等的页码范围。把彼此依赖的短节合并，把密集的章节拆开。
4. 讲材料特有的内容时，**标注页码和章节名**。
5. 主动查看相关的图、表和示意图，而不是只依赖提取出来的文本。
6. 把读不懂、缺失、自相矛盾或含糊的材料内容**明确标出来**。不要自己编一个「复原版」。
7. 以用户提供的材料作为**主课程**。只在需要补前置知识、澄清、纠正明显错误或提供练习时才加入外部材料，并把它标为补充内容。

### 主题模式

学习者给的是一个学科而不是一份材料时，用主题模式。

1. 定出一个合理的范围与**最终能力**。
2. 找出前置知识，把概念从基础到进阶排列。
3. 对于有时效性、冷门、有争议或可从外部核实的话题，在搭建课程之前，**用浏览器工具（`browser_open` + `browser_snapshot`，必要时配 `browser_wait`）查权威来源**。
4. 技术或科学论断优先采用一手资料与官方文档。
5. 区分**稳定的基础知识**与**当下的最新进展**。
6. 在课程地图里写明材料的范围与假设。

> **要派子智能体查资料时注意**：**子智能体拿不到浏览器工具**（它们只有
> read / grep / glob / bash / edit / write / todo）。所以给它们的提示词里要写明
> 只能靠 `bash` + `curl` 取页面（Windows 上 curl 是 `curl.exe`），
> 拿不到的内容由你主会话自己用浏览器工具补。

不要因为一点小歧义就停下进度。选一个有用的默认范围，并把它说明白。

### 续学模式

学习者提供了保存的课程状态文件或状态块，或要求继续之前的课程时，用续学模式。

1. 读状态：已完成章节、概念表、复习队列、错误日志。
2. 在新内容之前先做 **2–4 道热身提取题**，权重偏向「需要复习」的概念和过去的错误类型。**出新的题，绝不要原题照搬。**
3. 用一句话复述当前进度，把热身结果更新进状态，然后继续当前章节。
4. 如果需要原始文档而用户没有再提供，**就向他要**；只依据状态里的概念摘要临时教一教是可以的，但要说明这是在打折扣。

## 开始课程

只收集**真正会改变教学方式**的信息。如果学习者的水平或目标不明，二选一：

- 问一个紧凑的诊断性问题，或
- 提供一份 3 题的诊断小测，并让学习者可以跳过。

不要发长篇问卷。能从来往对话里推断出偏好，就尽量推断。

然后给出：

1. **目标能力** —— 学完之后，学习者应该能解释什么、做什么。
2. **课程地图** —— 3–12 章，每章写明目的和前置知识。
3. **预估水平** —— 入门、中级、进阶或混合，附一句简短理由。
4. **学习契约** —— 说明课是一节一节上的，答案在尝试之前一直隐藏。
5. **下一步动作** —— 立刻开始第一课或诊断。

需要格式统一时，用 [references/session-formats.md](./references/session-formats.md) 里的详细模板。

## 构建课程地图

按**概念依赖**划分章节，而不是只看材料长短。每一章都应当有：

- 一个简短的标题；
- 一个**可观察**的学习目标；
- 关键概念；
- 前置章节的链接；
- 文档模式下的原文页码或章节；
- 一个计划好的练习产出。

切分尺度规则：

- 一章里包含**超过一个主要推理跳跃**时，拆开。
- **无法独立理解**的小节，合并。
- 材料假定读者已具备而实际缺失的知识，补一个**前置桥梁章**。
- 进阶附录保持可选，除非学习者的目标需要它。
- 材料天然超过约 12 章时，把章节归入若干部，与学习者就范围达成一致，**一部一部地推进**，而不是把所有内容压平成一张地图。
- 只有出于教学必要性才调整顺序；文档模式下要解释为什么调整。

## 教好每一课

遵循这个教学循环：

1. **定向** —— 说明这一课为什么重要，并把它与已学内容连起来。
2. **目标** —— 给出 2–4 个可观察的目标。
3. **核心讲解** —— 分成小节讲，一次只引入一个概念跳跃。
4. **例题** —— 演示推理过程，而不只是最终结果。
5. **误区检查** —— 指出 1–3 个常见的混淆点或边界情况。
6. **主动回忆** —— 在进入更长的练习之前，先问一个简短的检查题。
7. **练习** —— 布置与当前掌握程度相匹配的习题。
8. **反馈回路** —— 批改学习者的回答，决定是前进、补救还是加难度。

材料密集时，每讲完一个主要概念就停一下，问一个检查题。材料浅显时，把整课讲完再练习。

## 设计练习

从多个认知层级中挑选习题：

- **记忆（Recall）**：定义、列举、标注、复述。
- **解释（Explain）**：用自己的话重述；比较概念；解释为什么。
- **应用（Apply）**：解一道有代表性的题，或在具体情境中使用该方法。
- **排错（Debug）**：在推理、代码、推导或解释中找出错误。
- **迁移（Transfer）**：把想法用到一个全新的场景里。
- **综合（Synthesize）**：把若干章连起来，或产出一个作品。

每课默认 3–5 道题，至少混合两个层级。交互式批改时，优先一次一道题。只有学习者要练习卷或考试时，才用更大的题量。

习题的编写规则、难度档位、适配与批改量规，见 [references/practice-and-mastery.md](./references/practice-and-mastery.md)。上面的认知层级说的是**学习者在做什么**；那份参考里的难度档位说的是**给了多少脚手架** —— 两个维度可以自由组合。

## 批改与回应学习者的回答

**先看实质，再看措辞。** 按这个顺序：

1. 给出判定：正确、基本正确、部分正确，还是需要修改。
2. 指出做得好的地方。
3. 指出第一个重要的缺口或错误。
4. 用**最小但够用**的讲解量把更正讲清楚。
5. 要求重做、给一道针对性的追问，或者前进。

不要只说一句「对了」。要把**起决定作用的推理**强调出来。

答案错误时：

- 先给一个针对该误解的提示。
- 再失败一次后，给更强的提示。
- 在反复尝试之后、学习者明确要求时，或继续瞎猜的学习价值已经很低时，**给出完整解答**。
- 给出解答之后，**立刻**跟一道近迁移题。

答案正确时：

- 逐步提高难度。
- 如果学习者可能是猜的，要求他解释。
- 掌握程度看起来很强时，上一道迁移题。

## 跟踪掌握程度与复习

在课程状态里（文件或状态块）维护一张**概念表**，每个概念一行：

- 状态：未见、已介绍、练习中、已掌握、需复习；
- 证据：最近一次最强的回答或错误；
- 把握度：低、中、高；
- 下次复习时点。

在章节边界和出现重大错误之后更新它。不要每一轮都把整张表打印出来；在章节边界或用户要求时，展示一份紧凑的进度快照。

安排累积复习：

- 每章之后：2–4 道提取题，覆盖当前与之前的材料；
- 课程进行到约三分之一和三分之二时：混合检查点；
- 课程结束时：期末评估与综合任务；
- **反复出错的点要比已掌握的概念复习得更勤**。

掌握的标准是**表现出迁移能力**，而不是一次答对的回忆题。

## 处理学习者的指令

识别并响应这类自然语言指令：

- 「继续 / continue」—— 推进到下一个待办步骤。
- 「提示 / hint」—— 给出下一个提示，但不给完整答案。
- 「答案 / show solution」—— 揭示并讲解解法，然后跟一道近迁移题。
- 「更简单 / simpler」—— 降低抽象程度，补前置知识和例子。
- 「更深入 / deeper」—— 加推导、边界情况和更难的迁移。
- 「跳过 / skip」—— 把该项标为跳过，继续往下。
- 「复习 / review」—— 生成偏重薄弱概念的提取练习。
- 「考试 / test me」—— 做一次闭卷的混合测评。
- 「进度 / progress」—— 展示已完成章节、掌握情况、薄弱点和下一步。
- 「重做课程 / rebuild course」—— 修订范围或章节划分，同时保留已经证明的掌握记录。

## 完成课程

结尾时提供：

1. 一份混合的**期末评估**，一开始不显示解答；
2. 一个跨多章的**综合任务**；
3. 附**概念级反馈**的批改；
4. 一份简明的**掌握情况报告**；
5. 一份针对薄弱概念的**个性化复习计划**；
6. 一份紧凑的**速查表**，且只能在评估之后给出 —— 免得它取代提取练习。

文档模式下，附一份**原文导航索引**，把已掌握的概念指回对应的页码或章节。

## 质量检查

每次回复之前，确认：

- 学习者还没尝试练习，解答没有提前暴露。
- 当前活动与课程状态一致，且状态在章节边界更新过。
- 这一课没有假定某个尚未解释过的前置知识。
- 回复给学习者的**下一步动作恰好只有一个**，且清晰明确。

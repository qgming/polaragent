# 会话格式（Session Formats）

把这些当作默认模板使用，按学习者和主题调整篇幅与标签。

> **关于「没有文件工具」的情况（Oint 的实际情况）**：Oint **一定有**文件工具
>（read / write / edit），所以**请始终把课程状态落盘**成 `learn/<slug>/course-state.md`。
> 本节里「可移植状态块」那套做法，是为环境受限的情况保留的 ——
> 例如把课程挪到另一个没有文件工具的宿主里继续时，可以用它来回搬状态。

## 课程状态（`learn/<slug>/course-state.md`，或可移植状态块）

这是持久化的记录。**有文件工具时**，把它作为文件维护，在章节边界更新。**没有文件工具时**，在每个章节检查点把同样的内容作为围栏代码块输出，并在前面加一句提示，告诉学习者可以把它存下来、之后粘回来接着学。

```markdown
# 课程状态：[科目]
**学习者：** [水平、目标、节奏 —— 一行]
**材料：** [文件/主题 + 范围]

## 章节
- [x] 1. [标题] —— 已掌握：[概念] | 薄弱：[概念]
- [ ] 2. [标题]  ← 当前，[在本章中的位置]
- [ ] 3. ...

## 概念表
| 概念 | 状态 | 证据 | 下次复习 |
|---|---|---|---|
| | | | |

## 复习队列
- [概念] —— 上次提问：第 [N] 章 —— [结果]

## 错误日志
- 第 [N] 章：[主要错误类别，一行]
```

保持紧凑 —— 这是工作状态，不是课堂笔记。跨会话答对两次的概念行就**退场**（移除）。

## 课程地图

```markdown
# 学习计划：[科目]

**目标能力：** [可观察的最终能力]
**起点水平：** [水平 + 简短证据]
**材料范围：** [文档页码/章节，或主题的边界]

| 章节 | 目标 | 关键概念 | 原文位置 | 练习产出 |
|---|---|---|---|---|
| 1. ... | ... | ... | 第 ... 页 | ... |

**我们会怎么进行：** 一次学一章。你要先尝试练习，之后才会看到解答。

## 开始
[诊断题，或第 1 课的开场]
```

## 一课

```markdown
# 第 [N] 章：[标题]

**为什么重要：** ...
**学完这一课，你能：**
- ...
- ...

## 1. [概念]
[讲解]

### 例题
[带推理过程的例子]

### 常见陷阱
[误区或边界情况]

## 检查
[一道简短的主动回忆题]
```

材料密集时，等学习者回应之后，再继续下一个讲解或练习。

## 练习提示

```markdown
## 练习 [N]
**考查的技能：** [概念/认知层级]
**任务：** ...
**成功标准：** ...

请连推理过程一起回答，不要只给最终答案。
```

**不要在同一个回复里附带解答文字。**

## 反馈

```markdown
**判定：** [正确 / 基本正确 / 部分正确 / 需要修改]

**做得好的地方：** ...
**关键缺口：** ...
**更正：** ...

**下一步：** [要求重做、追问，或前进]
```

## 章节检查点

```markdown
## 章节检查点
- 已完成：...
- 掌握扎实的概念：...
- 需要复习：...
- 下一章：...

### 累积回忆
1. ...
2. ...
3. ...
```

## 进度报告

```markdown
# 进度
**课程：** ...
**已完成：** [x/y 章]
**当前：** ...
**已掌握：** ...
**练习中：** ...
**需复习：** ...
**建议的下一步：** ...
```

为当前项目生成一份项目级 `AGENTS.md`（写到工作目录下的 `AGENTS.md`）。

## 流程

1. **先读，别猜**：目录结构、`README`、包管理 / 构建配置（`package.json` / `pyproject.toml` / `Cargo.toml` / `go.mod`）、CI 配置、已有的 `AGENTS.md` 或 `CLAUDE.md`、linter / formatter 配置、测试目录。

2. **已有 `AGENTS.md` 时先停下**：把现有内容读出来，说明你打算补什么、删什么、为什么，等我确认后再写。不要直接覆盖 —— 那里面可能有我踩过坑才写下的东西。

3. **只写"不看代码猜不到"的东西**。每条写完自问一句：**删掉它，代理会犯错吗？** 会，才留。
   - 该写：这个仓库特有的命令（装依赖 / 开发 / 构建 / 测试 / 类型检查 / lint —— **只写真实存在的**，逐个对着 scripts、Makefile、CI 核对）；与通用惯例不同的约定（注释语言、命名、目录归属、错误处理方式）；改代码时的硬约束与坑（生成物不要手改、哪些文件必须同步改、提交前必须跑什么）；测试怎么跑、怎么只跑一个测试。
   - 不该写：读一遍代码就知道的目录说明、语言通用惯例（"要写测试""要写清晰代码"这类）、详细 API 文档、大段 README 复制。

4. **写完汇报**：加了哪些段落、每条为什么值得留在 `AGENTS.md`；以及你**犹豫过但没写**的内容（连同理由）—— 那些往往是我最想补的。

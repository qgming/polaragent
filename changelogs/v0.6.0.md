# 更新日志

## [0.6.0] - 2026-02-27

本次 0.6.0 是一次大规模架构精简与 UI 重构。移除了整套内置助手体系，全面适配 pi-agent-core 0.85 原生 API，设置页改为模态窗并重新分类，侧边栏与顶部栏布局对齐现代桌面应用范式。

### 🧹 移除内置助手体系

- **删除全部内置助手**：移除内置助手 JSON、助手广场、AgentsPage、AgentEditorModal、agents-market-store
- **移除输入框/会话头助手选择**：对话不再关联特定助手
- **简化模型路由**：`model-router` 统一使用默认 Provider/Model，不再按助手路由
- **简化 agent-manager**：改为单一全局 AgentHarness 运行时
- **精简 delegate_task**：仅保留 `temporaryAgentName` + `temporarySystemPrompt` 创建临时子代理，删除 `list_agents`
- **清理 agentId**：会话 meta、定时任务 payload、聊天 store 中的 agentId 全部移除

### 📝 全局 AGENTS.md

- **设置页新增 AGENTS.md 面板**：路径固定 `{dataDir}/AGENTS.md`，始终启用
- **首启自动创建**：安装时写入默认协作伙伴提示词，用户可在设置中编辑
- **系统提示注入**：harness 创建时读取 AGENTS.md 并注入系统提示

### ⚡ pi 0.85.1 原生 API 适配

- **工具层全面迁移**：所有内置工具从旧 `AgentTool` 签名改为 `AgentHarnessTool` 原生签名
- **删除兼容适配器**：移除 `toHarnessTool` 包装层与 0.84/0.85 兼容注释
- **toolContext 注入**：改为 harness 的 `toolContext` 选项注入，不再闭包捕获

### ⚙️ 设置页重构

- **整页改为模态窗**：SettingsPage 改为 Dialog 形式，侧边栏按钮直接打开
- **分类合并**：12 个分区精简为 6 个（通用/模型/知识与检索/记忆与指令/自动化/关于）
- **知识库嵌入并入模型面板**：不再单独占一个导航项
- **AGENTS.md 改名「个性化」**：与全局记忆独立
- **UI 风格对齐 MiMo**：加大圆角、缩小尺寸、左栏搜索、卡片边框与间距统一

### 🎨 全局 UI 优化

- **移除使用教程**：删除 TutorialPage、全部 Guide 组件与 i18n
- **移除顶部栏菜单**：主题/更新/关于已由设置模态窗覆盖
- **全局配色统一**：右侧纯白 `bg-white`，侧边栏 `#f8f7f5`，深色模式保留
- **滚动条优化**：宽度 6px，去掉上下箭头按钮
- **布局重构**：侧边栏到顶（品牌+搜索+折叠），内容区独立顶栏（标题+按钮+窗口控制）
- **侧边栏纵向分组**：项目与会话改为独立可折叠分组，带展开收起动画
- **侧边栏细节**：「最近」改名「会话」，分组箭头移到标题右侧，移除底部重复新建按钮

### 🔧 依赖与工程

- **pi 依赖**：`@earendil-works/pi-agent-core` 与 `@earendil-works/pi-ai` 保持 `0.85.1`
- **完整验证**：`typecheck`、`test`（23 tests）、`build` 全部通过

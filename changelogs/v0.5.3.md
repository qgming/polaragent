# 更新日志

## [0.5.3] - 2026-07-31

本次 0.5.3 重点升级 PolarAgent 的桌面端工程架构与安全边界。Electron 主进程、IPC 和 preload 已统一迁移到 TypeScript 与 Vite 构建链路，同时修复生产启动、发布测试和安全模式校验问题，并清理不再使用的旧模块，为后续桌面能力迭代提供更稳定的基础。

### 🏗️ 桌面架构升级

- **Electron 主进程迁移到 TypeScript**：原 `electron/` 下的 CommonJS 主进程、IPC 和公共模块迁移到 `src/main/`，统一纳入类型检查与构建流程
- **Preload 迁移到 TypeScript**：安全桥接入口迁移到 `src/preload/`，由 Vite 生成独立 preload 产物
- **统一多进程构建**：引入 `vite-plugin-electron`，`npm run build` 现在会同时检查并构建 renderer、主进程和 preload
- **独立 Electron 类型检查**：新增 `tsconfig.electron.json`，隔离主进程 Node/Electron 类型与 renderer 浏览器类型
- **打包配置独立化**：Electron Builder 配置迁移到 `electron-builder.yml`，安装包统一包含 `dist/`、`dist-electron/` 和应用资源
- **开发流程简化**：`npm run dev` 由 Vite 统一启动 renderer 与 Electron，移除旧的并行进程与端口等待脚本

### 🔐 安全与稳定性

- **Renderer 沙箱启用**：BrowserWindow 启用 sandbox，并阻止页面自行创建新窗口
- **外部链接收口**：合法 HTTP/HTTPS 链接统一交由系统浏览器打开
- **安全模式输入白名单**：主进程只接受 `readonly`、`safe`、`ai_review` 和 `full` 四种模式，非法 IPC 值不再退化为完全权限
- **环境变量安全兜底**：无效的 `POLARAGENT_SECURITY_MODE` 会回退到默认 `ai_review`
- **关键路径边界修复**：不再把 `C:\Windows.old`、`/usr-local` 等同前缀相邻目录误判为系统目录
- **生产启动兼容修复**：启动包装会清理 `ELECTRON_RUN_AS_NODE`，避免主进程被错误地当作普通 Node.js 脚本执行
- **开发模式数据加载修复**：主进程 watcher 不再清空共享的 `dist-electron`，避免 preload 产物被删除后所有 IPC 数据接口失效

### 🧭 技能发现

- **发现导航重做**：技能页由单一广场改为知名 Skills 网站导航，可直接通过系统浏览器访问社区目录、官方集合与开放标准
- **移除 SkillsMP 接入**：删除 SkillsMP 搜索、缓存、IPC 请求和偏好设置中的 API Key 配置，减少启动时的后台网络请求

### 🧪 测试与发布

- **恢复自动化测试入口**：重新接入 Vitest，并新增安全模式与关键路径回归测试
- **修复发布工作流**：解决 GitHub Actions 执行 `npm test` 时因脚本缺失而必然失败的问题
- **完整构建验证**：renderer、主进程和 preload 的类型检查与生产构建均已通过
- **Windows 打包验证**：Windows x64 unpacked 应用已验证包含 renderer、主进程和 preload 产物

### 📦 依赖与工程维护

- **核心 Agent 依赖升级**：`@earendil-works/pi-agent-core` 与 `@earendil-works/pi-ai` 升级到 `0.83.0`
- **桌面与构建依赖升级**：Electron 升级到 `43.2.0`，Vite 升级到 `8.2.0`，TypeScript 升级到 `7.0.2`
- **前端依赖升级**：React / React DOM 升级到 `19.2.8`，并同步更新 Radix UI、i18next、lucide-react、Tailwind CSS 与 pdfjs-dist
- **清理废弃模块**：移除不再使用的 GoalPanel、旧 Widget patch engine、JSONL 辅助模块和过期类型出口
- **配置与文档同步**：更新构建脚本、README、锁文件与发布说明，版本统一为 `0.5.3`
